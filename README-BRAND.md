# TopInjector: дизайн-система «Прогрев»

## Идея

Страница имеет температуру. Она открывается на холодной шлифованной стали и
нагревается по одной непрерывной дуге до полного горения у кнопки действия.
Это не украшение: градиент кодирует само обещание продукта, а сквозная рейка
слева отсчитывает позицию с 47 до 1 по мере скролла.

Референс: приборный мануал Teenage Engineering, оранжевый дрэнч Klim.

## Почему не тёмный лендинг с оранжевым акцентом

Первая версия была именно такой, и это оказался типовой ход категории: сначала
все отвергают белый фон конкурентов, потом одинаково приходят в «тёмное с одним
горячим акцентом». Проверка из `impeccable/reference/brand.md`: если описание
страницы подходит модальному лендингу категории, начинай заново. Подошло.

## Что зашито в вёрстку

- **Одна температурная дуга.** `.heat-ramp` в `globals.css`. Секции лежат на ней
  прозрачно, своего фона не имеют.
- **Зоны вместо глобального цвета текста.** Каждая секция объявляет
  `zone-cold`, `zone-warm`, `zone-hot` или `zone-burn`. Зона задаёт `--ink`,
  `--rule`, `--btn-bg` и остальное под конкретный участок фона. Менять цвет
  текста напрямую нельзя, иначе он разъедется с градиентом.
- **Кнопка инвертируется на оранжевом.** В `zone-hot` `--btn-bg` становится
  почти чёрным: оранжевая кнопка на оранжевом фоне не читается.
- **Скруглений почти нет.** `--radius-panel: 3px`. Углы фрезерованные, не надутые.
- **Никаких карточек с иконкой в скруглённом квадрате.** Структуру держат
  волосяные линейки, сетка и нумерация.
- **Две гарнитуры.** Onest говорит, Martian Mono измеряет. Обе с кириллицей,
  проверено. Все цифры идут через класс `.num`.
- **Подписи-кикеры максимум трижды на страницу.** Повтор капсовой подписи над
  каждой секцией читается как шаблон.
- **Ноль длинных тире.** Только обычный дефис.
- **Одна формулировка на одно действие.** Все кнопки регистрации подписаны
  одинаково.

## Материал страницы

Две прослойки в `globals.css`, обе обязательны.

**Крапчатость.** Вплетена прямо в `background-image` у `.heat-ramp` рядом с
градиентом и смешана через `background-blend-mode: soft-light`. Смешивание
внутри собственной отрисовки одного элемента стоит куда дешевле отдельного слоя
с `mix-blend-mode`, и прокручивается вместе с контентом бесплатно, поэтому
текстура читается как материал страницы, а не как плёнка поверх неё.

Постеризацию через `discrete` пробовал и убрал: она давала жёсткие контуры,
которые в тёмной зоне превращались в кляксы-«материки». Нужна мягкая
крапчатость, а не карта высот.

**Дизеринг.** Класс `.dither` на `body`. Градиент тянется примерно на 9000
пикселей через восемь опорных точек, это около 35 пикселей на один 8-битный шаг
цвета при пороге заметности около 8. Без мелкого шума поверх градиент разбивается
на видимые полосы. Слой зафиксирован, поэтому прокрутка его не перерисовывает.

## Тепловая поверхность первого экрана

`heat-surface.tsx`. WebGL-поверхность за первым экраном: курсор впрыскивает
тепло, оно расплывается по турбулентности и остывает примерно за полторы
секунды. Без курсора греется сама по медленному дрейфу.

Почему именно так, а не иначе:

- **Изотермы, а не свечение.** Гладкое радиальное затухание читается как
  mesh-градиентный блоб, то есть как прямой AI-штамп. Разбивка поля на ступенчатые
  контуры читается как показание тепловизора, чем страница и является.
- **Только до тёплого, никогда до оранжевого.** Первый экран это холодный конец
  страницы, сайт стоит на 47 позиции. Пылающий герой противоречил бы всей
  логике прогрева. Настоящий огонь приходит внизу.
- **Пик ограничен 0.54.** Выше текст перестаёт читаться.

Условия, которые нельзя снимать:

- При `prefers-reduced-motion` не инициализируется вообще.
- Без WebGL не инициализируется, остаётся статичный градиент. Он запасной
  вариант по замыслу, а не деградация.
- Рендер на паузе вне экрана и при скрытой вкладке.
- Плотность пикселей ограничена 1.5, иначе телефоны задыхаются.
- Замерено 76 кадров в секунду при цели 60.

Ловушка, на которой этот эффект уже один раз молча сломался: адрес
uniform-массива надо запрашивать как `uPoints[0]`. По голому имени часть
драйверов возвращает null, все точки читаются нулями, и поверхность остаётся
ледяной без единой ошибки в консоли.

## Движение

Токены в `globals.css`. Длительности выведены из замера реальных эталонных
продуктов, а не придуманы: на linear.app микровзаимодействия идут за 100-160мс
и на одной кривой. Переходы в 300-500мс это главная причина, по которой
интерфейс ощущается обычным.

| Токен | Значение | Для чего |
| --- | --- | --- |
| `--t-press` | 100мс | Нажатие, отклик на палец |
| `--t-hover` | 150мс | Ховер, цвет, границы |
| `--t-panel` | 240мс | Панели, меню, гамбургер |
| `--ease-out` | `cubic-bezier(0.23, 1, 0.32, 1)` | Появление, вход |
| `--ease-micro` | `cubic-bezier(0.25, 0.46, 0.45, 0.94)` | Микровзаимодействия |
| `--ease-haptic` | `cubic-bezier(0.32, 0.72, 0, 1)` | Ящики, шторки |

Правила, которые легко нарушить при доработке:

- **Никогда `transition: all`.** Всегда перечисляйте свойства поимённо.
- **Никогда `ease-in` в интерфейсе.** Он стартует медленно ровно в тот момент,
  когда пользователь смотрит внимательнее всего, и всё кажется тормозящим.
- **Анимировать только `transform` и `opacity`.** Остальное дёргает раскладку.
- **Нажатие это `scale(0.975)`**, а не сдвиг.
- **Ховер только за `@media (hover: hover)`.** На тапе он даёт ложные срабатывания.
- **Ничего не появляется из `scale(0)`.** В реальном мире предметы не возникают
  из ничего, минимум `scale(0.95)` плюс прозрачность.
- **Один момент восторга на страницу.** Счётчик 47 → 03 в первом экране играет
  один раз при первом появлении: он показывает само обещание продукта. Разложить
  такое по всей странице значит обесценить.

Развёртка заголовка через `clip-path` живёт в `heat-reveal.tsx` и применяется
только к `h1`. Это тепло, идущее по металлу, а не общий эффект для всего подряд.

## Логотип

Знак пламени сейчас нарисован кодом в `src/components/logo.tsx` как приближение
к присланному. Чтобы поставить настоящий:

1. Положите файл в `public/logo.svg`.
2. Замените компонент `Flame`:

```tsx
import Image from "next/image";

export function Flame({ className = "h-7 w-7" }: { className?: string }) {
  return <Image src="/logo.svg" alt="" width={28} height={28} className={className} priority />;
}
```

Словесная часть набрана шрифтом, а не картинкой: остаётся резкой и читается
поисковиками.
